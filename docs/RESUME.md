## Library Management & Digital Lending System | TypeScript, Node.js, Express, MySQL

- Engineered an OOP-driven library backend using TypeScript, Express.js and MySQL with abstract user models, inheritance, polymorphism and layered controller-service-repository architecture
- Implemented JWT authentication, bcrypt password hashing, role-based authorization, OTP email verification, book search, lending/returns and automated overdue fine calculation through REST APIs
- Designed an indexed relational schema with users, books, loans, OTP and audit-log entities; enforced referential integrity and atomic inventory updates using MySQL transactions and row-level locking
- Added pagination, API validation, Swagger/OpenAPI documentation, rate limiting, security middleware, Docker deployment and automated Jest unit tests for core business logic
